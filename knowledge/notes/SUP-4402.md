## Problem

sheet; QA validated it on 2026-07-27 against a POT tracking sheet. The session

## Diagnosis path

1. **`*_pct_ttl` metrics (asked as "add new metrics").** They already existed
   in `HistoryFit.pivotdefn:399-401` and `HistoryFitStyle.pivotdefn:524-526`
   as self-divisions (`net_sls_r / net_sls_r`), so always 100% or 0. Cause: the
   column sits in `params.COMPUTED_METRICS`, evaluated inside the GROUP BY query
   where no grand total exists. Reference pattern: `HistoryProductivity` and
   `HistoryAggregateViewsNestedAttribute_for_CatRecap` wrap the result and
   `CROSS JOIN` a no-GROUP-BY `sum()` subquery. Chosen: remove the stubs and wrap
   the second `reverseAggSQLs` entry. (`aggregationSQLs` is empty and unused in
   this pivot family, which ends in `reverseAggSQLs`.)
2. **"Funded Store/Web APS R/U" label rename.** Grep: 0 hits for the "R"
   labels, 18 hits for the "U" labels in 6 viewdefn files; the target format
   `Funded APS U (Store)` is already the dominant convention elsewhere.
   `text` only, `dataIndex` untouched. User chose to rename the U labels only.
3. **Net MMU $ shows `($2.35K)`.** Dead end as a bug: value is genuinely
   negative (`net_sls_margin_r = net_sls_r - net_sls_c - perm_md_c`,
   `HistoryGrid_Companion.pivotdefn:129`; API payload `-2352.61`, margin -1.6%).
   Brackets come from `usMoneyRounded` = `numbro(value).format('($0.00a)')` in
   assortmentui `src/utils/Domain/Renderer.tsx` (accounting-style negatives; the
   `usMoney` and `usMoneyNoCents` renderers have no parens). Per-tile option:
   switch the renderer in the viewdefn.
4. **Net MMU $ variance shows 0%.** Root cause:
   `HistoryAggregateViewsNestedAttribute_for_CatRecap.pivotdefn:3480`
   `CASE WHEN ly_net_sls_margin_r > 0 THEN round((ty-ly)/ly,4) ELSE 0 END`.
   LY margin was negative (-$24.02K), the guard `> 0` fails and falls to a hard
   `0`. Same guard shape repeats ~75 times (`var_ly_*`) and ~62 times
   (`var_lly_*`) in the file and in 5 sibling pivots. A plain `<> 0` guard would
   yield -148% for a loss-to-profit swing, so a product decision (show N/A when
   signs differ) was requested; not recorded as answered.
5. **Region group-by fails in Style Color Review > Collection View.**
   ClickHouse `Code: 47 Unknown column name 'global_region'`. In
   `include/history_metrics_ty.ftl:671-682` the `ANY LEFT JOIN
   {tenant}_INV_LOCATION_{session}` (and the location/cluster filters) that
   would bring in store attributes is commented out (since the file's first
   commit `4388236`, 2026-05-12). Store-level group-bys work because those
   columns exist on the receipts table; `global_region` only exists on
   `store_hier_attr`. The include is shared by `HistoryFit`,
   `BU_HistoryGridStyleColor`, `HistoryByStore`. Proposed: uncomment the join.
   Not executed (no CH access in session).

## Knowledge gained (techno-functional — required)

**Technical:** (a) the QA override bucket holds only changed files, so the
override tree contains pivot/uidefn only and must be overlaid, never `--delete`
mirrored (the session wiped 118 files that way and restored them); the sync
flattens under `--dest-dir`; the bucket prefix also holds `mfp/` overrides.
(b) a metric needing a grand total cannot live in `params.COMPUTED_METRICS`.
(c) `ly_x > 0` guards silently zero out variance when LY is negative.
(d) a group-by dimension must be reachable from the table the pivot reads;
check the join before the column.

**Functional:** Net MMU = net sales minus cost minus permanent markdown cost; a
negative value means markdown plus cost exceeded revenue (accounting brackets).
Variance versus LY is not meaningful when the LY base is zero or the sign flips;
planners usually want "NM". `pct_ttl` means share of the in-scope grand total.

## Gotchas

- Git diff after a QA overlay shows large unrelated drift (e.g. SUP-4330
  eComm/Store channel split); isolate your own hunks.
- Brackets on negatives are platform-wide for all `*Rounded` money renderers
  (`euroRounded` too); changing the renderer hits every client.
- Open items for the next person: variance rule for sign flips, and the
  Region join fix and its fan-out check on `store_hier_attr`.
